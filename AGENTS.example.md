# Project guidance for Codex

Select skills by task relevance, not all at once. Use frontend-uiux for browser UI; android-apk for Android; backend-apis for services; database-engineering for persistence; quality-security for tests and security; context-token-efficiency for large-context work. Combine at most one domain skill plus context-token-efficiency unless the task crosses domains. Preserve existing functionality and credentials. Search before reading, make minimal patches, test impacted flows and report evidence. Never claim a build or test succeeded without executing it.

Use playwright-browser for automated E2E testing; playwright-interactive-browser for supported persistent browser debugging; openai-api-docs for OpenAI SDK/API work; screenshot-review for visual screenshots; implementation-plan for multi-phase projects. Load only relevant skills.
