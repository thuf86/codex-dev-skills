# Instruções do projeto para Codex

Selecione as skills por relevância, nunca todas ao mesmo tempo. Use `frontend-uiux` para interfaces web, `android-apk` para Android, `backend-apis` para serviços, `database-engineering` para persistência, `quality-security` para testes e segurança, e `context-token-efficiency` para tarefas com contexto extenso.

Use `playwright-browser` para testes E2E, `playwright-interactive-browser` para depuração interativa quando houver ferramentas, `openai-api-docs` para integrações OpenAI, `screenshot-review` para problemas visuais e `implementation-plan` para mudanças em várias fases.

Preserve funcionalidades, endpoints e credenciais existentes. Pesquise arquivos e símbolos antes de ler grandes volumes de código. Faça alterações mínimas, execute testes direcionados e relate resultados reais. Nunca declare sucesso de testes ou builds que não foram executados.
