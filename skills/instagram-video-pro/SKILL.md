# Instagram Video Pro — Claude Code + Codex

Skill de direção audiovisual e produção para Instagram em pt-BR. Não publica automaticamente.

## Activation
Use for requests to create Instagram Reels, Stories, video shorts, subtitles, editing, scripting or audiovisual QA. For NULL TRACE: the feed carousel standard remains exactly 7 separate 1080x1350 images; videos are distinct deliverables.

## Workflow
1. Define audience, goal, topic, factual sources, duration, aspect ratio, narration, assets, publishing permissions and rights. Apply sensible defaults when unspecified.
2. Verify dynamic factual and cybersecurity claims via authoritative sources where available. Record evidence and provenance rather than inventing incidents, statistics or citations.
3. Create opening hook (0–2s), 3–6 scene beats, structured storyboard, concise voiceover in pt-BR, CTA, title/cover and complete caption.
4. Inspect user-provided media. Use external video/image/voice generation only through authorized installed services, with explicit permission to upload and record license, model and prompt. If not available, use graphic slides rather than falsely claiming photorealistic video.
5. Follow reference/creative-direction.md. Convert storyboard into editable templates/project.example.json style JSON. Use scripts/render.py to create a graphic Reel, or optionally installed Remotion for motion graphics. Ensure text-safe regions.
6. Include optional locally provided voiceover/music only with confirmed rights. Avoid unlicensed popular audio and unauthorized voice cloning.
7. Execute scripts/validate_video.py and manual visual, listening and spelling review. Validate 1080x1920, 30 fps, H.264, safe legibility, captions, pacing and sources.
8. Deliver MP4, project JSON, thumbnail idea, caption/hashtags, attribution manifest and exact QA results. Only publish when separately authorized and an actual supported integration is available.

## Guardrails
Do not leak tokens or sensitive materials, fabricate real event screenshots, or publish/delete Instagram content without explicit authorization. Distinguish Reels from still-image carousels. Never claim to have generated assets or rendered a video without actual tool evidence. Preserve other projects. The bundled renderer generates typography slides; it is not text-to-video AI. Social platform limits can change.

## Deliverable
Report output path, size, duration, codecs, caption/CTA, creative choices, sources and asset licenses, actual validation status and outstanding manual checks.
